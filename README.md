**assistr**

*Handbuch für neue Coaches*

davidinho2303.github.io/wiesel2-dashboard/Drill.html

**Warum assistr?**

assistr ist eine digitale Coaching-Plattform, die zunächst im Rahmen der Weddinger Wiesel veröffentlicht wird.

**Alle Drills deines Teams — immer dabei.**

Du hast die gesamte Drill-Bibliothek des Teams immer griffbereit, filterbar nach Kategorie, Phase, Intensität und Spielerzahl. Drill antippen → vollständige Beschreibung, Coaching-Punkte, Bild.

Neuen Drill anlegen? Kurz beschreiben oder Foto vom Whiteboard oder altem Notizzettel machen — assistr erkennt automatisch alle Metadaten. Fertig.

**Trainingsplanung in Minuten — nicht in Stunden.**

Pläne aus Zeitblöcken aufbauen, Drills per Suche zuweisen, Minuten anpassen. Die Gesamtzeit rechnet sich automatisch. Auf Knopfdruck exportieren — als PDF, Druckversion oder WhatsApp-Text für die Gruppe.

**Immer den Überblick über die Saison.**

Phasen definieren, Wochenziele setzen, Schwerpunkte festlegen. assistr zählt automatisch jeden gespeicherten Plan mit und zeigt dir wie dein IST gegen dein SOLL steht — welche Kategorien du trainiert hast und welche zu kurz kamen.

**Als Team arbeiten, nicht nebeneinander.**

Drills und Trainingspläne teilen oder für dich behalten — du entscheidest. Was du teilst, ist sofort für alle Coaches sichtbar. Was andere teilen, kannst du direkt übernehmen und anpassen.

**Einloggen**

Beim ersten Start erscheint ein Login-Screen. Kürzel eingeben (z.B. "max", "anna") und Speichern tippen.

- Nur Kleinbuchstaben und Zahlen — wird automatisch erzwungen

- Kürzel merken — es ist dein einziger Zugang bis Google Login implementiert ist

- Falls das Kürzel schon vergeben ist, erscheint eine Warnung

| 💡 | *Das Kürzel ist kein Passwort — wer es kennt kann sich damit einloggen. Für den Vereinsbetrieb ist das bewusst so gewählt.* |
| --- | --- |

**Navigation**

Mobile: Bottom-Navigation mit 5 Tabs. Desktop: Sidebar links.

| **Tab** | **Inhalt** |
| --- | --- |
| Drills | Drill-Bibliothek — suchen, filtern, importieren, anlegen |
| Plan | Trainingsplan aufbauen, Drills zuweisen, exportieren |
| Tracking | Drill-Einsatz über die Saison auswerten |
| Übersicht | Alle gespeicherten Pläne auf einen Blick |
| Saison | Saisonphasen definieren, Kalender, IST/SOLL-Tracking |

**Drills**

**Suchen ****&**** Filtern**

Die Bibliothek ist nach allen relevanten Dimensionen filterbar:

- Freitextsuche nach Drill-Name

- Kategorie: Passing, Ballhandling, Shooting, Defense, Offense, ...

- Trainingsphase: Warmup / Hauptteil

- Spielphase: Technik, SO (Set Offense), OT, DT, SD

- Intensität: niedrig / mittel / hoch

- Min. Spieler: filtert Drills die mit weniger Spielern funktionieren

- Scope: Public / Team / Meine

**Drill-Detail**

Drill antippen → vollständige Beschreibung, Variationen, Coaching-Punkte, Bild/Video. Von hier direkt zum aktiven Trainingsplan hinzufügen.

**KI-Import**

Der schnellste Weg einen neuen Drill anzulegen. Kein Formular ausfüllen — assistr erkennt alle Metadaten automatisch.

- "KI-Import" in der Bibliothek antippen

- Text: Drill frei beschreiben — ein oder mehrere, kein festes Format

- Datei: Foto, PDF, Word, CSV oder Textdatei hochladen

- Analysieren tippen — Ergebnis prüfen, bei Bedarf anpassen, speichern

| 💡 | *Auch Screenshots aus anderen Coaching-Apps oder PDFs funktionieren.* |
| --- | --- |

| 💡 | *Viele Drills auf einmal zum Start? Schick sie an david.schreiber+assistr@weddinger-wiesel.de — Foto, PDF, Word oder Text, Kürzel im Betreff. David importiert sie einmalig für dich.* |
| --- | --- |

**Drill manuell anlegen**

Button "+ Neuer Drill" → Formular ausfüllen → Speichern.

- Sichtbarkeit: Public (alle Teams) / Team / Privat

- "Als Constraint verwendbar" aktivieren wenn der Drill als Regelset auf andere Drills gelegt werden kann — er erscheint dann im Constraint-Modal des Trainingsplans

**Plan**

**Plan erstellen**

- Tab "Plan" öffnen → Template laden oder "+ Leerer Plan"

- Datum, Gegner / Thema, Gesamtzeit eintragen

- In jedem Block "+ Drill auswählen" → suchen, filtern, antippen

- Minuten pro Drill anpassen, Reihenfolge per Drag & Drop

**Blöcke**

- Warmup & Stretching sowie Abschluss: fix vorgegeben, Dauer anpassbar

- Hauptteil-Blöcke: frei bespielbar, verschiebbar, löschbar

- "+ Block hinzufügen" erstellt einen neuen freien Block

**Constraints**

Regelsets die auf einzelne Drills im Plan gelegt werden — z.B. "Max. 3 Dribbles" oder "Help the Helper".

- Unter jedem Drill im Plan: Constraint-Button antippen

- Aus der Liste wählen oder eigenen Text eingeben

- Mehrere Constraints gleichzeitig möglich, einzeln entfernbar

**Speichern ****&**** Export**

- "Speichern" → Plan ist in der Cloud, sofort auf allen Geräten sichtbar

- Schloss-Icon: Plan sperren gegen versehentliches Überschreiben

- Export: PDF/Drucken, WhatsApp-Text, JSON, CSV

- "Tpl." Button: Plan als Template speichern — erscheint oben im Plan-Tab für schnellen Zugriff

**Tracking ****&**** Übersicht**

**Tracking**

Auswertung welche Drills wie oft in gespeicherten Plänen eingesetzt wurden.

- Datumsfilter: beliebigen Zeitraum wählen

- Drill-Rangliste: sortiert nach Einsatz-Häufigkeit

- Kategorie-Auswertung: welche Bereiche das Training dominieren

**Übersicht**

Alle gespeicherten Pläne auf einen Blick — filtern, öffnen, exportieren.

- Pläne nach Datum, Thema oder Gegner filtern

- Plan direkt öffnen und weiterbearbeiten

- Sammel-Export aller gefilterten Pläne

**Saison**

**Phasen anlegen**

- "+ Phase" → Name, Zeitraum, Farbe, Wochenziel

- Schwerpunkte: Kategorien mit optionalem %-Ziel

- Phase erscheint im Kalender als farbiger Balken

**Kalender**

- Phasen als farbige Balken über den Tagen

- Tage mit gespeicherten Plänen sind markiert — antippen für Details

- "Liste" / "Kalender" umschalten

**IST / SOLL**

- Gezählte Trainings vs. Wochenziel pro Phase

- Kategorien-Balken: IST-Verteilung gegen definierte Schwerpunkte

- Alle Pläne der Phase aufgelistet, direkt öffenbar

**Team ****&**** Berechtigungen**

**Kürzel ****&**** Rollen**

- Jeder Coach hat ein eigenes Kürzel

- Admin: kann alle Inhalte bearbeiten und löschen

- Coach: kann eigene und geteilte Inhalte bearbeiten

**Sichtbarkeit**

- Public — sichtbar für alle Teams und User

- Team — nur für Mitglieder des eigenen Teams

- Privat — nur für den Ersteller

| **Inhalt** | **Sehen** | **Bearbeiten** | **Löschen** |
| --- | --- | --- | --- |
| Public Drills | Alle | Ersteller + Admin | Ersteller + Admin |
| Team Drills | Team-Mitglieder | Ersteller + Admin | Ersteller + Admin |
| Eigene Drills | Nur ich | Nur ich | Nur ich |
| Geteilte Pläne | Alle | Alle | Ersteller + Admin |
| Eigene Pläne | Nur ich | Nur ich | Nur ich |
| Plan-Templates | Je Scope | Ersteller + Admin | Ersteller + Admin |

**Mobile**

- Home-Bildschirm: "Teilen" → "Zum Home-Bildschirm" — App verhält sich wie nativ

- Erster Start: kurz warten bis alle Drills aus der Cloud geladen sind

- Exportieren: Teilen-Button → "In Dateien sichern" oder "Drucken" → Als PDF speichern

- Kein Netz: Bereits geladene Inhalte bleiben im Cache — Speichern und Sync benötigen Verbindung
